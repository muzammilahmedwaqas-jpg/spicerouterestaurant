# Spice Route Restaurant - Staff Attendance & Shift Management System
A robust, enterprise-ready Staff Attendance and Shift Management web application built for **Spice Route Restaurant**, featuring role-based access control, secure check-in/check-out tracking, leave workflows, and monthly streaming CSV reports.
---
## 🚀 Tech Stack & Architecture
* **Backend Framework:** Laravel 13 (PHP 8.4)
* **Frontend:** Bootstrap 5, Blade Templates, Responsive UI
* **Database:** SQLite (`database/database.sqlite`)
* **Deployment & Containerization:** Custom Docker (`nginx` + `PHP-FPM`) configured for cloud hosting (Render).
---
## ⚙️ Environment Variables (.env)
To run this application successfully, configure your environment variables with the following keys. A standard production or local configuration requires:

| Variable | Description | Example Value |
| :--- | :--- | :--- |
| `APP_NAME` | Application Name | `SpiceRoute` |
| `APP_ENV` | Environment mode | `production` / `local` |
| `APP_KEY` | Encryption key generated by Laravel | `base64:...` |
| `APP_DEBUG` | Enable/disable debug mode | `false` / `true` |
| `APP_URL` | Base URL of the application | `https://spicerouterestaurant.onrender.com` |
| `DB_CONNECTION` | Database driver | `sqlite` |
| `LOG_CHANNEL` | Logging stack | `stack` |
| `LOG_LEVEL` | Logging verbosity | `debug` |
